# DezignPool favicon package

Generated from `public/assets/images/dezignpool-split-ribbon.png`.

- Browser icons use the exact gold split-ribbon mark on transparency.
- Apple and Android icons use the same mark on the DezignPool charcoal background.
- Android icons include mask-safe padding for adaptive launchers.
- `index.html` and `site.webmanifest` carry a cache version so the retired DP-square icon is not reused.
